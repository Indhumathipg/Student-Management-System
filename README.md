# Student Management System Using C

## Description
A simple console-based application developed using C programming to manage student records. It allows users to add, view, search, update, and delete student details. Student information is stored automatically in a text file using file handling.

## Features
- Add student details
- View all student records
- Search for a student
- Update student details
- Delete student records
- Store data in a text file

## Technologies Used
- C Programming Language
- Structures
- File Handling
